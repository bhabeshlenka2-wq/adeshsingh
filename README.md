# Adesh Singh Originals — Premium Portfolio

This is a static HTML/CSS/JS portfolio with separate Photography and Video sections, cinematic loading animation, scroll reveals, cursor interaction, hover transitions, animated background, responsive mobile navigation and contact icons.

## Add photos
Place these files in `assets/images/`:
- festival-day.jpg
- night-temple.jpg
- park-at-night.jpg
- festival-lights.jpg
- sunset-landscape.jpg

## Add videos
Place these files in `assets/videos/`:
- showreel.mp4
- cinematic.mp4
- reel.mp4

The supplied AS Originals logo is already included as `assets/images/logo.jpeg`.

## GitHub/Vercel
Upload the CONTENTS of this folder to the GitHub repository root. For Vercel, import the repository as a static site; no build command is required.
